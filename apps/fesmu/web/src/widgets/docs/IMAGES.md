# Файлы для статей документации

Всё, что показывается/скачивается из статей, лежит в `apps/fesmu/web/src/public/docs/`:

```
src/public/docs/
├── img/      картинки и скриншоты — счётные имена: 1.png, 2.png, 3.png …
└── files/    документы для скачивания: pdf, docx, xlsx …
```

Отдаётся с корня сайта: `img/1.png` → `/docs/img/1.png`, `files/x.pdf` → `/docs/files/x.pdf`.

## Картинка в статье

В `src/widgets/docs/docs.data.tsx`:

```tsx
<DocImage
  n={1}
  alt="Что на картинке — обязательно, читают скринридеры и видно, если файл не загрузился"
  caption="Необязательная подпись под картинкой"
/>
```

- `n={1}` → берётся `/docs/img/1.png`
- `ext="jpg"` — если файл не `.png`
- `dir="staff-sso-guide"` — подпапка внутри `img/` (`/docs/img/staff-sso-guide/1.png`)

Если файла нет — компонент ничего не рисует, статья не ломается.
Клик по картинке открывает её крупно.

## Документ для скачивания

Кладём в `files/`, ссылаемся напрямую:

```tsx
source: {
  href: "/docs/files/dormitory_rules_2026.pdf",
  label: "Положение об общежитиях ДВГМУ (PDF)",
}
```

## Форматы

PNG для скриншотов интерфейса, JPG для фото. Ширину исходника держим
≈ 1200–1600 px, вес — до ~300 КБ (пережимать перед коммитом).
