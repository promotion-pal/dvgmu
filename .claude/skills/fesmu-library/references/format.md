# Формат исходников сида

## Методичка — один файл `.md`

В начале — свойства карточки, дальше — темы.

```
---
title: Методика сестринского наблюдения при заболеваниях органов дыхания
discipline: Сестринское дело
specialty: Сестринское дело
course: 2
semester: 3
authors: Кафедра сестринского дела с курсом социальных дисциплин
annotation: Одна-три фразы для карточки в списке методичек.
---
```

`title` и `discipline` обязательны. Методички на странице группируются по `discipline`, поэтому
у всех методичек кафедры по одному предмету дисциплина пишется одинаково. `course` и `semester`
указывают числом, 0 — не указано. Пределы: discipline 255, title 512, specialty 255,
authors 512, annotation 4096 символов.

### Обычный Markdown

| В файле | В методичке |
| --- | --- |
| `# Заголовок` | не блок; title, если его нет в свойствах |
| `## Тема` | тема (раздел оглавления) |
| текст до первой `##` | тема «Введение» (строки вроде даты и автора экспорта лучше удалить) |
| `### …`, `#### …`, `##### …` | подзаголовки уровней 2, 3, 4 |
| абзацы, списки `- …`, `1. …` | блок «текст» с разметкой `**жирный**`, `*курсив*`, `[ссылка](https://…)` |
| таблица `\| … \|` | блок «таблица», первая строка — шапка |
| короткий абзац, кончается на `:`, сразу перед таблицей | подпись таблицы |
| строка `**Название:**`, сразу за ней `1. … 2. …` | чек-лист (алгоритм) с этим названием |
| `---` в теле | разделитель |

В ячейках таблиц и шагах чек-листов разметка не отображается: скрипт её снимает.
Экранирование из экспорта (`\[Е\]`, `&#91;`) снимается автоматически.

### Вставки

Вставка — блок в тройных обратных кавычках: вид, параметры, `|` и заголовок.

````
```callout important | Методика
Текст с разметкой. Тоны: info (справка), important (важно),
warning (осторожно, безопасность), clinical (клиническая заметка).
```

```checklist | Алгоритм измерения АД
Объяснить пациенту ход измерения.
Наложить манжету на 2–2,5 см выше локтевого сгиба.
```
(`checklist unordered | …` — без номеров; «1.» и «- » в начале строк снимаются)

```case | Задача 1. Удушье ночью
Условие — любой текст до первого вопроса.
? Какое состояние развилось?
? Составьте алгоритм помощи.
Ответ:
Эталон — текст с разметкой до конца вставки.
```

```quiz | Самоконтроль
? Вопрос
+ верный вариант
- неверный вариант
+ ещё один верный (несколько «+» — множественный выбор)
> пояснение, показывается после ответа
```

```glossary
Ортопноэ — вынужденное положение сидя с опущенными ногами.
```

```video https://rutube.ru/video/… | Подпись
```
````

Рисунки и вложения (`figure`, `attachment`) через сид не добавляются: файлы хранит сервис
файлов, и зарегистрировать их может только api. Их добавляют в редакторе методички после сида.
Блок «Литература» тоже не сеется: id изданий каталога известны только после вставки.
Литературу дают таблицей или текстом.

## Издания каталога — `items.json`

Сид добавляет только **ссылки** (`LIBRARY_ITEM_KIND_LINK`): ЭБС, сайт издательства, открытый PDF.
Файлы изданий загружают через раздел «Библиотека»: api кладёт их в сервис файлов.

```json
[
  {
    "title": "Педиатрия с детскими инфекциями",
    "authors": "Запруднов А.М., Григорьев К.И.",
    "year": 2011,
    "publisher": "ГЭОТАР-Медиа",
    "discipline": "Сестринское дело",
    "description": "Учебник для медицинских колледжей.",
    "url": "https://www.studentlibrary.ru/…"
  }
]
```

`title` и `url` обязательны, url — только http(s). Пределы: title и authors 512, publisher и
discipline 255, description 8192 символа, год 1800–2100 или 0.
Издание с теми же title и url повторно не вставляется.
